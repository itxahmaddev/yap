How it works

One shortcut.
Four seconds.

  1. 01

    Press

    Hold your shortcut to record, or tap it to toggle. You pick the keys.

  2. 02

    Speak

    Talk normally. Silero VAD trims the silence before the model hears it.

  3. 03

    Release

    Whisper, Parakeet or another local model transcribes on your machine.

  4. 04

    Done

    The text is pasted straight into the app you were already using.

Features

Does one thing.
Does it everywhere.

Offline, all the way down

Models download once, then everything happens locally. Pull the network cable and Yap keeps working.

micvadmodelpaste

GPU accelerated

Metal on macOS, Vulkan on Windows and Linux, with a fast CPU path when there's no GPU.

Skips the silence

Voice activity detection drops the pauses, so transcripts come back faster and cleaner.

Hold or tap

Push-to-talk, toggle, or both on one key. Any shortcut you like.

Pastes anywhere

Email, chat, code editor, terminal. If it has a text box, Yap can type into it.

Speaks your language

Multilingual models with automatic language detection. The app itself ships in 26 languages.

Transcribe files

Drop in an audio or video file and the transcript lands in History.

Optional cleanup

Run the text through a prompt of your own before it's pasted. Off unless you set it up.

Scriptable when you want it

Drive a running instance from the command line, bind it in your window manager, or add a transcription hook that rewrites text before Yap pastes it. 

$ yap --toggle-transcription

Local history

Every transcription is kept on your machine to copy, save, or re-transcribe later.

FAQ

Questions,
answered.

Something else? Ask in Discussions.

Is Yap really free?

Yes. Yap is MIT licensed with no account, no subscription and no usage limits. The full source is on GitHub.

Does it need an internet connection?

Only to download the app and the models you pick. After that, transcription runs entirely on your computer, with or without a connection.

Which model should I start with?

On a CPU, Parakeet V3 is fast and detects your language automatically. With a capable GPU, Whisper Turbo or Large gives the best accuracy. You can switch any time.

What permissions does it ask for?

Microphone access to hear you. On macOS it also needs accessibility permission so the global shortcut and pasting work.

Does it work on Linux with Wayland?

Yes, with some limits. Install wtype or dotool for text input, and bind yap --toggle-transcription to a shortcut in your desktop environment.

Can I transcribe recordings I already have?

Yes. Drop an audio or video file onto Yap and the transcript shows up in History.
