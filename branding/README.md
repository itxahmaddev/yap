# Branding

Official Yap logos. Use these files rather than redrawing the logo.

| File                 | Use                                  |
| -------------------- | ------------------------------------ |
| `yap-logo-black.png` | Wordmark for light backgrounds       |
| `yap-logo-white.png` | Wordmark for dark backgrounds        |
| `yap-mark-black.png` | Icon-only mark for light backgrounds |
| `yap-mark-white.png` | Icon-only mark for dark backgrounds  |

The README uses this folder. The app bundles its own copies in
`src/assets/brand/`, and the website keeps its own in `website/assets/`, so each
can be built and deployed on its own. If you change a logo, update all three.
