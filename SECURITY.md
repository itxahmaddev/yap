# Security Policy

## Supported Versions

Yap is pre-1.0. Security fixes are made against the latest release only.

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |
| older   | No        |

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report privately using GitHub's
[private vulnerability reporting](https://github.com/itxahmaddev/yap/security/advisories/new),
or email **itxahmad.dev@gmail.com** with:

- a description of the issue and its impact
- steps to reproduce, or a proof of concept
- the affected version and operating system

You can expect an acknowledgement within a few days. We will keep you updated
while the issue is fixed and credit you in the release notes unless you prefer
to stay anonymous.

## Scope and Privacy

Yap runs speech recognition locally and does not send audio to a server.
Reports about unintended network access, data leaks, unsafe handling of
clipboard or keyboard input, or the download of models and updates are in scope.
